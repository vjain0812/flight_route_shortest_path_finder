About This App

This tool models the global air route network as a directed weighted graph — airports are nodes, and routes are edges. Edge weights are great-circle distances (km) computed from real GPS coordinates.

Dijkstra's Algorithm finds the path with the minimum total distance flown — the fewest kilometers in the air.
BFS (Breadth-First Search) finds the path with the fewest number of stops, ignoring distance.

Comparing both reveals that the "shortest" route depends on what you're optimizing: distance or layovers. Dataset: OpenFlights (~7,000 airports, ~67,000 routes).
